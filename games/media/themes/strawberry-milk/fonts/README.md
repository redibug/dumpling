# Theme fonts

`squarecaps.ttf` belongs here — SquareCaps by George Williams
(https://www.1001fonts.com/squarecaps-font.html), licensed under the
SIL Open Font License, used for the chapter drop caps.

Download it from the link above and drop the TTF in this folder
as `squarecaps.ttf`. Until then the drop caps fall back to serif.
